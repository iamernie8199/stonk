菜鳥研究員

我先問最基本的。勤誠到底是什麼公司？我以前一直把它當成伺服器機殼廠，但最近大家講它都講得很像 AI 基礎設施受惠股。

資深研究員

這就是理解勤誠最重要的起點。

如果用舊框架看，勤誠確實就是 server chassis 廠，也就是伺服器機殼與機構件供應商。但如果你還停在這一層，就會低估這家公司這兩年真正被市場重估的原因。

現在更準確的說法是：
勤誠正從單純的伺服器機殼供應商，升級成 AI 資料中心 rack-level 機構件與整合方案供應商。

菜鳥研究員

什麼叫 rack-level 機構件？為什麼這句話比「機殼廠」重要很多？

資深研究員

因為「機殼廠」講的是單機，「rack-level」講的是整櫃。

以前市場看勤誠，多半是在看：
- 伺服器機殼出貨量
- 伺服器景氣循環
- 產品單價提升

但 AI 資料中心時代，客戶要的不只是單台 server 機殼，而是整個 rack 裡面一整串機構件能力：
- Compute tray
- Switch tray
- Storage tray
- Rack frame
- Power shelf
- Cable management
- 液冷相關固定結構
- CDU rack

所以勤誠現在被重估，不是因為它多賣幾個機殼，而是因為它有機會從單機走向整櫃。

先講第一條，勤誠已不只是跟著一般伺服器需求波動，而是直接吃到 AI 平台專案。

公司本質

  • 勤誠不是傳統機殼廠，而是 AI 資料中心機構件從 chassis 往 rack-level integration 升級的受惠公司。
  • 真正值錢的不是箱體數量，而是每個 AI 平台帶進來的高價值機構件內容與平台角色提升。

已知事實

  • 勤誠目前站在 AI server / ASIC / rack solution 升級鏈上，市場已不再只把它當一般 server chassis 供應商。
  • 最新台灣交易日的市場定價，已明顯把它放進 AI 資料中心機構件升級股框架。
  • 目前研究主線集中在 AWS ASIC、HGX、Helios、CDU 與 rack-level 機構件滲透提升。
  • 市場正在交易的，不只是伺服器景氣，而是它能否從單點專案受惠者，轉成可延續的平台型機構件供應商。

同業定位

  • 誰最純：勤誠若從 AI 機構件與整櫃化切角來看，純度高於一般 server chassis 同業。
  • 誰最廣：廣達、緯穎這類整機與系統平台廠更廣，但不以機構件內容值為核心。
  • 誰最穩：大型平台型 ODM 或既有資料中心整機供應商通常更穩。
  • 誰最有彈性：勤誠若 rack-level 與高價值機構件滲透成立，獲利彈性會高於傳統機構件同業。
  • 本公司卡在哪裡：它正卡在「專案型高峰股」與「AI 機構件平台股」的估值分界上。
  • 最像的比較對手：具 AI server 機構件與整櫃化切入能力的 chassis / rack solution 供應商。
  • 最不像的比較對手：只靠傳統 server 機殼量增、缺乏平台化內容值的板金或箱體供應商。

估值五件組
