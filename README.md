## 🛠️ 技術架構與儲存庫管理

本專案採用 Git 雙分支結構維護：

```
stonk/ (GitHub Repository)
 ├── source 分支 (主儲存庫)
 │    ├── render_dialogue_reports.py   ← Python 靜態 HTML 生成器
 │    ├── reports/stocks-dialogues/    ← Markdown 原始對話報告檔
 │    └── .gitignore                   ← 設定檔與快取排除
 │
 └── main 分支 (GitHub Pages 部署分支)
      ├── index.html                   ← 彭博風格報告索引首頁
      ├── stonk_logo.png               ← 品牌 Logo
      ├── TW-XXXX_公司名_*.html         ← 各個股一頁式 HTML 深度報告
      └── README.md                    ← 本說明文件
```

### 本地建置與運行

```bash
# 複製原始碼分支
git clone -b source https://github.com/iamernie8199/stonk.git
cd stonk

# 執行生成器渲染最新 HTML 報告與索引頁面
python render_dialogue_reports.py
```
