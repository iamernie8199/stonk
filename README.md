## 🛠️ 技術架構

```
render_dialogue_reports.py   ← Python 靜態 HTML 產生器 (source branch)
      │
      ▼
reports/stocks-dialogues/html/
      ├── index.html           ← 首頁卡片索引
      ├── stonk_logo.png       ← 品牌標誌
      ├── TW-XXXX_公司名_*.html ← 各個股一頁式深度報告
```

- **留言**：Giscus (GitHub Discussions)
