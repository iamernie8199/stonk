本專案為 **台股死當 — 深度對話式研究報告** 的靜態 HTML 生成系統。核心程式 `render_dialogue_reports.py` 能自動解析 Markdown 格式的 AI 個股對話報告，將其轉化為極具質感的彭博終端機（Bloomberg Terminal）風格 Web 介面。

---

## ✨ 系統核心功能

1. **彭博終端機 UI 渲染 Engine**：
   - 全站採用高對比深色主題、等寬字型、LIVE 綠點動態呼吸燈與電晶體 Terminal 質感設計。
2. **多維度分類與主題聯動篩選**：
   - 支援 12 大產業分類標籤 (F1: AI 伺服器 ~ F12: 測試介面) 與投資主線 (Thesis) 的雙向聯動篩選與模糊搜尋。
3. **報告內容萃取與目錄結構化**：
   - 自動提取 Markdown 中的對話紀錄、短評摘要、投資主線與「最短版記法」。
   - 生成專屬「資深研究員精華摘要版 (Senior Digest)」與自動導覽目錄 (TOC)。
4. **即時檢索與索引頁生成**：
   - 自動掃描 `reports/stocks-dialogues/` 目錄下的個股報告檔，並即時編譯產出 `index.html`。
5. **Giscus Discussions 留言板整合**：
   - 各 HTML 報告預設整合 Giscus GitHub 討論區，便於社群留言交流。

## 📁 專案結構與 Git 雙分支管理

本 repository 採用雙分支管理設計：

- **`source` 分支**（本分支）：存放靜態報告生成器源碼 `render_dialogue_reports.py` 及原始 Markdown 報告檔。
- **`main` 分支**：存放生成後的 HTML 頁面及 `index.html` 首頁，用於 GitHub Pages 網站發布與託管。

```
.
├── render_dialogue_reports.py     # Python 靜態 HTML 生成器核心
├── reports/
│   └── stocks-dialogues/          # 原始 Markdown 研究報告檔
│       └── html/                  # [git submodule / main 分支] 產出的 HTML 報告庫
│           ├── index.html         # 網站首頁
│           └── TW-*.html          # 各個股一頁式研究報告
├── .gitignore                     # 排除快取與備份檔
└── README.md                      # 本說明文件
```

## 🚀 快速開始 (Quick Start)

### 環境需求
- Python 3.8+ （僅需 Python 標準庫：`pathlib`, `re`, `html`, `json`, `datetime`）

### 執行報告生成
```bash
# 執行轉換腳本，自動讀取 reports/ 內的 markdown 檔案並更新 html 報告與 index.html
python render_dialogue_reports.py
```
