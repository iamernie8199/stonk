第 1 段
菜鳥研究員

我先從最基本的開始。力旺到底是做什麼的？我知道它常被歸在矽智財 IP 股，但老實說我對這種公司很沒感，因為它不像台積電那樣有晶圓廠，也不像聯發科那樣賣晶片，那它到底在賣什麼？

資深研究員

如果你要一句話先記住，力旺本質上不是晶片設計公司，也不是晶圓製造公司，而是把非揮發性記憶體與硬體安全功能做成可授權的矽智財 IP 公司。

也就是說，它賣的不是一顆自己品牌的晶片，而是：
- 讓客戶在晶片裡內建記憶體功能的 IP
- 讓客戶在晶片裡加上安全驗證與信任根能力的 IP
- 讓晶片在不同製程節點都能可靠運作的設計 know-how

所以你可以把它理解成：
客戶要做晶片，不想自己從零開發這些高難度功能，就去買力旺的 IP 授權，把它整合進自己的 SoC 或控制晶片裡。

先進製程與先進封裝
菜鳥研究員

所以力旺不是賣成品，而是賣設計模組？

資深研究員

對，這個方向是對的。

更精準一點說，力旺賣的是被嵌進客戶晶片裡的關鍵功能模組，而且這些功能不是可有可無，而是很多晶片都需要：
- OTP（一次性可編程記憶體）
- PUF（防偽安全、硬體信任根）
- MTP（可重複程式化記憶體）
- 與先進製程相容的 eNVM / 記憶體相關 IP

所以力旺值錢的地方，不是它做終端產品，而是它站在整個晶片設計流程的前端，而且一旦被客戶導入，通常就不太容易換掉。

先進製程與先進封裝
菜鳥研究員

那市場現在為什麼這麼重視力旺？只是因為 IP 授權毛利高嗎？

資深研究員

如果只是因為 IP 授權毛利高，力旺當然會有吸引力，但市場重視它，不只是因為它高毛利而已。

現在市場重估力旺，有幾條線一起在發生：
- 先進製程越來越複雜，客戶更依賴成熟的 IP 供應商
- 硬體安全需求提升，PUF / trust root 類型 IP 重要性上升
- OIP / PDK 早期協同開發讓先進製程 IP 廠更有護城河
- Chiplet、異質整合、埃米級製程讓記憶體與安全 IP 的整合難度更高
- 力旺不是只吃授權金，還能透過量產後的權利金持續受益

先進製程與先進封裝
菜鳥研究員

所以如果一句話講，力旺不是單純的 IP 題材股，而是先進製程與安全需求升級下的基礎設施型 IP 公司？

資深研究員

對，這句話很準。

如果你要更精準一點，我會這樣說：
力旺不是單純賣授權的 IP 小公司，而是站在先進製程、晶片安全與記憶體功能交叉核心的基礎設施型矽智財供應商。

先進製程與先進封裝
菜鳥研究員

那如果一句話講力旺現在最重要的身份，你會怎麼定義？

資深研究員

我會這樣定義：
力旺不是單純的矽智財授權商，而是先進製程、記憶體功能與硬體安全升級過程中，站在晶片設計基礎層的高稀缺 IP 供應者。

- 本益比 79.2 倍

- 總市值 2,036 億元

再看月營收，最新依月份語意正確解讀，是 2026 年 7 月營收，公告日 2026-08-05：

這組數字很有意思。它不像成熟 IP 股那麼平滑，而是會受到授權金認列與權利金節奏影響，所以波動看起來很大。但市場沒有因此把它當景氣循環股，反而願意用接近 80 倍本益比看它，這代表市場在交易的是更長期的 IP 稀缺性。

先進製程與先進封裝
菜鳥研究員

79 倍本益比也很誇張。市場到底在賭什麼，才願意給這種估值？

資深研究員

對，這就是研究力旺最重要的第一步。

力旺現在的高估值，不是因為短期營收漂亮而已，而是市場在賭幾件事：
- 先進製程越往下走，客戶越依賴成熟 NVM / 安全 IP
- PUF 等硬體安全 IP 會因 AI、邊緣運算與新型架構而更重要
- OIP / PDK 協同開發地位會讓力旺持續占到更早期的設計入口
- 授權金 + 權利金雙軌模式，能讓它不只一次收費，而是長期吃量產紅利

先進製程與先進封裝
菜鳥研究員

那力旺現在最重要的成長主線，到底是什麼？一句話怎麼講？

資深研究員

一句話講，就是：
力旺最重要的成長主線，是先進製程與硬體安全需求升級，讓它的 NVM IP、PUF 與相關安全 / 記憶體 IP 從利基功能，升級成晶片設計流程裡更不可缺的基礎能力。

拆開來看有四層：
- 先進製程節點越來越複雜，客戶越不想自己重做這些高風險功能
- 硬體安全需求上升
- OIP / PDK 協同開發護城河
- 授權金 + 權利金雙軌商模

估值與市場預期
菜鳥研究員

所以力旺最值錢的地方，不只是它有高毛利，而是它卡在設計流程裡很早、很難被換掉的位置？

資深研究員

對，這句話非常關鍵。

很多人看到力旺，只會看到高毛利、IP 授權、營收波動，但市場真正願意給高估值的，不是因為它毛利高而已，而是：
- 它是不是 OIP / PDK 生態中的早期節點
- 它的 NVM / 安全 IP 是不是客戶非用不可
- 一旦導入後，切換成本是不是很高
- 權利金是不是能跟著客戶量產一起放大

晶圓代工與商業模式
菜鳥研究員

那 OIP / PDK 這件事真的有那麼重要嗎？聽起來很技術、很抽象。

資深研究員

其實非常重要，而且這種東西正是把技術故事變成投資故事的關鍵。

因為力旺這種公司，不是只靠終端需求，而是要先進入客戶設計流程。OIP / PDK 協同開發代表的是：
- 它能更早接觸先進製程節點
- 它能更早跟晶圓代工 / EDA / 客戶一起優化
- 它的 IP 更容易成為設計標配

第 11 段
菜鳥研究員

好，那我們現在就真的把同業比較講清楚。M31、Synopsys、Cadence、力旺，市場到底怎麼分工？

資深研究員

很好，這才是對的問法。

你可以先這樣粗分：
- M31：廣泛介面 / PHY / SerDes 型 IP 平台公司，市場定價重點是應用廣度與客戶擴散
- 力旺：NVM / OTP / PUF / 安全 IP 為核心的高稀缺功能型平台公司，市場定價重點是基礎功能深度與替代難度
- Synopsys：EDA + IP 的全球級終局平台，市場定價重點是設計流程控制權與生態鎖定
- Cadence：設計基礎設施與高階 IP 生態並重的全球平台，市場定價重點是工具鏈、設計生態與平台廣度

第 13 段
菜鳥研究員

那力旺跟 M31 最大的差別到底是什麼？

資深研究員

如果只講一句話：
M31 更像通用介面 IP / PHY / SerDes 等較廣泛矽智財平台的代表，而力旺更像在 NVM / OTP / PUF / 安全信任根這條利基但高稀缺的基礎功能線上，卡得更深的一家公司。

也就是說：
- M31 偏平台廣度
- 力旺偏功能深度

估值與市場預期
菜鳥研究員

那 Synopsys 跟 Cadence 為什麼還值得拿來比？

資深研究員

因為它們代表產業終局框架。

市場看 Synopsys / Cadence，不只是看某一類 IP，而是把它們放進：
- EDA + IP 雙平台
- 晶片設計流程控制權
- 製程入口與設計工具生態
這種更高層的框架裡。

所以它們對力旺的意義，不是商模完全相同，而是回答：
當一家公司不只是賣單點 IP，而是掌握設計流程某個極關鍵位置時，市場會給什麼終局估值框架。

先進製程與先進封裝
菜鳥研究員

那最後如果真的要選股，力旺在這組 peer 裡最大的優點跟最大的缺點，各是什麼？

資深研究員

最大的優點：
- 不像全球 EDA 巨頭那麼大，成長彈性沒那麼鈍
- 也不像廣泛型平台 IP 那樣容易被看成只是應用面擴張
- 同時有 NVM、OTP、PUF、安全信任根、OIP / PDK、授權金 + 權利金幾個故事可以疊加

所以它是非常典型的高稀缺功能型平台升級股。

最大的缺點：
- 估值已經很高
- 市場對新授權案、先進製程滲透與權利金放大的期待也非常高
- 只要有一項沒跟上，估值就很容易先修

先進製程與先進封裝
菜鳥研究員

好，那現在來最重要的。為什麼市場願意給力旺這麼高的本益比？

資深研究員

因為市場在交易的，已經不是一般授權型公司，而是：
- 高稀缺 IP
- 先進製程受惠
- 安全需求升級
- 雙軌商模的長期平台價值

市場願意給這種倍數，通常代表它相信幾件事：
- 授權金不只是短期認列，而是新案源源不絕
- 權利金會隨客戶量產長期放大
- PUF / NeoFuse / MTP / FinFET 相關 IP 的需求不只是一時現象
- OIP / PDK 地位會持續讓力旺留在高價值鏈前端

先進製程與先進封裝
菜鳥研究員

所以力旺最重要的，不只是 revenue curve，而是授權金、權利金與先進製程 / 安全需求能不能一起成立？

資深研究員

對，這句話非常準。

力旺最關鍵的，不只是營收成長，而是：
- 新授權案是不是持續增加
- 權利金是不是能跟量產一起上升
- PUF 等安全 IP 是否持續被更多應用導入
- 先進製程導入是不是越來越深

也就是說，真正要追的不是單月營收，而是授權金、權利金、製程升級與安全需求能不能一起成立。

先進製程與先進封裝
菜鳥研究員

那營業利益率與淨利率又要怎麼看？

資深研究員

營業利益率回答的是：
授權金與權利金成長有沒有真的轉成高品質的經營槓桿。

淨利率回答的是：
股東最後拿到的高毛利、高轉換率利潤，是否乾淨且可持續。

對力旺來說，高品質獲利至少要看到：
- 新授權案穩定增加
- 權利金隨量產與製程升級放大
- PUF / OTP / MTP / FinFET 等產品線持續滲透
- 市場逐步把它當成先進製程基礎層 IP 資產，而不是一般授權股

先進製程與先進封裝
菜鳥研究員

那估值分水嶺到底是什麼？

資深研究員

估值分水嶺不是營收創不創高，而是授權金、權利金、先進製程滲透與平台化能力，能不能一起把 2027 之後的獲利平台墊高。

如果可以，70~80 倍有平台化想像；
如果不行，市場就會把它切回一般高毛利授權股。

反方壓力測試
菜鳥研究員

如果我要扮演反方，我第一個問題會是：力旺會不會其實只是高毛利 IP 股，所以市場願意給它高估值，但未必真的有那麼強的長期成長？

資深研究員

這是最強反方之一，而且非常合理。

反方會說：
- IP 公司本來就高毛利
- 授權金認列有波動性
- 權利金成長可能受單一客戶或單一製程節奏影響

這個反方最厲害的地方在於，它不是否認力旺現在很好，而是質疑這種好能不能從高毛利授權生意，變成真正長期複利的平台資產。

先進製程與先進封裝
菜鳥研究員

那如果只能選一個最脆弱的驗證數字，你會選哪一個？哪個條件掉了，這篇 thesis 就要重寫？

資深研究員

如果只能選一個最敏感的，我會選：權利金是否能隨量產與先進製程滲透穩定放大。

原因很簡單：
- 授權金可以因單案而波動
- 技術故事可以很美
- 但如果權利金沒有長尾放大，市場就很難相信它是平台複利，而只會把它當高毛利授權公司

如果 thesis 失效，市場最可能把它切回的低級框架是：

差別在於：
- 前者看單案授權與短期營收認列
