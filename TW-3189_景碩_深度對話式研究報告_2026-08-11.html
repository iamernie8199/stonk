第 1 段

如果最白話地講，景碩是高階 IC 載板公司，而且它最值得研究的地方不是「它也是載板廠」這件事，而是它剛好站在這一輪 ABF 與 BT 載板雙重重估的交叉點。

很多人第一眼會把景碩當成和欣興、南電差不多的載板股，但這樣看太粗。

更準確地說：
- 欣興比較像平台型高階基板資產
- 南電比較像 ABF + BT 雙槓桿高彈性資產
- 景碩則更像 CPU substrate、ABF 與 BT 三條線一起驅動的載板彈性股

AI 驅動與產業脈絡

因為載板比一般 PCB 更靠近晶片本身。

你可以把它想成：
- 一般 PCB 比較像系統板
- 載板則是把 CPU、GPU、ASIC、記憶體這些高階晶片接進系統的中介層

當晶片越大、訊號越密、功耗越高，載板價值就會往上走。特別在 AI 與高效能運算時代，載板不再只是「有就好」，而是變成一種稀缺高規格資產。

第 3 段

一句話講：
景碩現在最重要的身份，是 CPU substrate 與 ABF / BT 載板雙重受惠的高階載板彈性資產。

第 4 段

我會把它濃縮成三條。

第一條，ABF 載板供需持續吃緊。
第二條，CPU substrate 尤其是 NVIDIA Vera CPU 相關需求提升。
第三條，BT 載板因同業減產與光模組需求延伸，重新被市場上修價值。

這三條一起發生，景碩就不只是單純的 ABF 景氣股，而是高階載板結構性升級的高彈性代表。

第 6 段

這就是景碩最值得研究的地方。

市場現在不是把它當傳統 PCB / 載板景氣股，而是在買三個東西：
- CPU substrate 的結構升級
- ABF 載板供需缺口與漲價
- BT 載板重新變值錢

也就是說，這不是單純「營收不錯」而已，而是市場相信它所在的位置正在從一般載板供應商，升級成高價值 substrate 資產。

第 7 段

因為它代表景碩不只是吃「載板大家都一起好」，而是可能吃到更高價值、更高單價的 CPU 平台升級。

公司頁裡很重要的一點是：多家來源都把景碩和 NVIDIA Vera CPU、一般伺服器 CPU substrate 綁在一起看。這意味著市場不是只看它賣更多 ABF，而是看它有沒有切進更高價值的 CPU substrate 環節。

第 8 段

目前至少有三組可以互相交叉的線索。

第一，Citi 很早就把景碩放進 Vera CPU 供應鏈核心受惠名單，甚至明講市佔超過 50%。
第二，富邦後來補充，FY27 Vera CPU 配比有機會超過 50%，營收貢獻超過 20%。
第三，Daiwa 更進一步提出，上限情境下 CPU 產品市佔可能從約 50% 再往更高走。

你不用把每個數字都當成鐵律，但至少可以確定：市場現在不是把景碩當一般 ABF 廠，而是把它放在 CPU substrate 升級的中心位置。

估值與市場預期

對，這就是景碩比一般「ABF 大家都好」更值得細看的原因。

ABF 漲價是景氣層，CPU substrate 是結構層。若兩者一起成立，市場願意給的估值就會比單純景氣股更高。

第 10 段

這正是景碩很有意思的地方。

一般人會以為 BT 是舊產品、ABF 才是新主角，但如果供給側出現變化，BT 反而可能成為高彈性加分項。

根據公司頁整理，多家機構都提到：
- 欣興、SEMCO 等減少 BT 供給
- 記憶體需求與光模組相關需求延伸到 BT 載板
- mSAP HDI 短缺甚至讓部分光模組改走 BT 載板路線

AI 驅動與產業脈絡

對，而且這點很關鍵。
