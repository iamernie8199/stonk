第 1 段
菜鳥研究員

我先從最基本的開始。群聯到底是做什麼的？我知道它跟 NAND、SSD 有關，可是市場最近又在講 AI 儲存、Boot Drive、EDSFF、PCIe Gen6、CXL。這家公司到底賣的是記憶體，還是控制器，還是整套解決方案？

資深研究員

如果你要一句話先記住，群聯本質上是一家記憶體控制晶片與 SSD 解決方案公司，核心不是自己去做 NAND 晶片，而是把 NAND 這種原始儲存媒介，透過控制器、韌體、模組整合與系統設計，變成可在消費性、工業級與企業級場景真正被使用的產品。

很多人一看到記憶體股，就直覺把它跟做晶圓或做 DRAM / NAND 原廠混在一起。但群聯的價值不在於自己擁有最多晶圓產能，而在於它扮演的是如何把記憶體用得更有效率、更穩定、更符合系統需求的關鍵角色。

第 2 段
菜鳥研究員

那控制器到底重要在哪？如果 NAND 原廠這麼強，為什麼控制器公司還能這麼重要？

資深研究員

這個問題很重要，因為它直接決定你要不要把群聯當成高品質公司看。

NAND 本身只是儲存介質，像原料。可是你要把這個原料變成一個真正可用、可管理、可穩定讀寫、可在不同場景運作的儲存產品，中間需要很強的控制能力。

控制器的重要性在於：
- 管理資料寫入 / 讀出
- 管理壞塊與耐用度
- 提升效能與穩定性
- 讓不同 NAND 顆粒與不同平台可以順利整合
- 在企業級場景中滿足可靠度、延遲、壽命與功耗要求

菜鳥研究員

所以群聯不是在跟美光、海力士這種公司做同一件事，而是比較像站在它們上面或中間的整合層？

資深研究員

對，這個方向是對的。

群聯不是 NAND 晶圓原廠，它更像是：
- NAND 控制器供應商
- SSD 解決方案供應商
- 把儲存產品做成可落地模組與平台的人

資深研究員

如果只是記憶體景氣回來，群聯可以受惠，但不一定會被市場用這麼高品質的方式重看。

現在市場在意群聯，有兩條線同時發生。

第一條，是傳統的 NAND / SSD 景氣循環改善。這會帶動出貨、價格、庫存修正與獲利回升。

第二條，也是更重要的一條，是 AI 與資料中心架構升級，讓儲存不再只是容量問題，而是系統設計問題。

Boot Drive 聽起來很普通，為什麼市場會這麼在意？

資深研究員

這就是典型看起來普通，但其實很有量的東西。

Boot Drive 本身不是最炫的高階 AI 零件，但只要大量 AI / server 基礎設施在建，伺服器節點啟動、管理、系統部署需要的基礎儲存就會跟著放量。

AI 驅動與產業脈絡
菜鳥研究員

那 EDSFF、PCIe Gen6 這些又代表什麼？

資深研究員

這些代表的是企業級儲存規格升級，不只是容量升級。

EDSFF 的意義在於，資料中心 SSD 的外型規格、功耗管理、密度與散熱要求都在變，這不是一般 consumer SSD 的邏輯，而是更高門檻的 enterprise platform 問題。

PCIe Gen6 代表的是：
- 傳輸速度更高
- 訊號完整性要求更高
- 主控設計更難
- 韌體與平台整合更重要

AI 驅動與產業脈絡
菜鳥研究員

那 CXL、memory tiering 跟群聯有多直接的關係？會不會有點太遠？

資深研究員

這個問題非常重要，因為這正是群聯研究裡最容易過度延伸的地方。

群聯不是 CXL DRAM 的核心供應商，但 memory tiering 的概念對群聯還是有意義。因為未來 AI server 的記憶體 / 儲存架構，不會只有單一層，而會變成：
- HBM
- DRAM
- CXL memory
- NVMe SSD 與企業級儲存

這個分層越複雜，代表儲存控制、資料搬移、系統整合的重要性越高。

同業定位

  • 群聯：高階控制器與企業級 SSD 解決方案受益者。
  • 普通記憶體循環股：景氣敏感度較高，但高附加價值控制器 / 韌體 / 平台整合能力較弱。
  • 高階儲存控制與解決方案公司：同樣受惠於 AI / 資料中心儲存升級，但未必像群聯一樣同時卡到 Boot Drive、企業級 SSD 與高階主控。
  • 最像的比較對手：高規格 SSD 主控 / 儲存解決方案同業。
  • 最不像的比較對手：單純 NAND 原廠或普通記憶體循環股。

估值五件組

  • 毛利率：回答高附加價值企業級儲存產品，是否真的在推升內容價值。
  • 營業利益率：回答高階控制器與平台整合能力，是否真的轉成更高效率的平台利潤。
  • 淨利率：回答股東最後拿到的利潤，是否由高價值儲存需求穩定推升。
  • 獲利品質：重點在高毛利、高附加價值企業級儲存產品與 AI 儲存敘事，能否持續把營收轉成高品質現金流。
  • 估值分水嶺：市場會不會持續把它留在結構性高平台獲利框架，而不是切回普通記憶體循環股。

關鍵推論

  • 群聯的價值不只是 NAND 景氣回升，而是更複雜的 memory / storage hierarchy 對高階儲存控制與整合能力的需求。
  • AI 與資料中心儲存架構升級，是帶動企業級 SSD、Boot Drive 與高階控制器需求上升的主線。
  • 市場現在交易的不是單一數字，而是高毛利與高成長，到底是景氣高點，還是結構性高平台的開始。
  • 最大投資風險不是沒有需求，而是如果未來只是 peak earnings，現在的低本益比不一定是便宜。

目前最大爭議點

  • 高毛利率可持續性是否成立。
  • Boot Drive 營收占比與 PCIe Gen6 主控進度能否持續落地。
  • 高毛利、高附加價值企業級儲存產品能否持續墊高 2027 之後的獲利平台。
  • 市場是否會繼續把它留在高平台獲利框架，而不是切回普通記憶體循環股。

反方壓力測試
